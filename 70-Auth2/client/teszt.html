🔐 API információk: 
POST  /api/auth/register  - Regisztráció
POST  /api/auth/login      - Bejelentkezés
DELETE /api/auth/delete    - Felhasználó törlése (JWT token szükséges!)

Token alapú törléshez előbb jelentkezz be, majd a böngésző konzolban állítsd be a tokent:

localStorage.setItem('token', 'itt_a_token');
